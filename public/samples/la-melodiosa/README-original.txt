For SFZ Version
---------------------
Tested with Sforzando adn Sfizz players.

Bass and treble has own voice selections, like real instrument.
Bass selector, CC20 has three separate voices assigned their numerical ranges.
0  - 41  Upper register
42 - 83  Lower register
84 - 127 Both registers

Treble selector, CC21 has three separate voices assigned their numerical ranges.
0  - 41  Upper register
42 - 83  Lower register
84 - 127 Both registers


For Decent Sampler version
--------------------------
The voice registers are in the user interface, just like in a real instrument.
