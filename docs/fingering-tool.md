# Fingering Tool

The Fingering Tool adds finger numbers to selected buttons or keys.

It is useful for:

- practice diagrams
- scale and chord fingering plans
- lesson materials
- comparing alternative fingerings

## Basic workflow

1. Select the button or key you want to annotate.
2. Open **Fingering** in the Tools panel.
3. Assign a finger number.
4. Choose where the number should appear.

## Finger placement

Finger numbers can be shown:

- inside the button near the bottom
- inside the button near the top
- above the button

The best placement depends on the diagram density and whether the button labels are visible.

## Treble and Stradella use

The Fingering Tool works in both Treble and Stradella diagrams.

For dense Stradella layouts, placing finger numbers above the button can make them easier to see. For piano or larger treble diagrams, inside placement is often more compact.

## Export

Finger numbers are included when downloading the diagram as SVG or PNG.

## Tips

Use Selection, Scale Finder, or Chord Finder first to highlight the relevant buttons. Then add finger numbers to make the diagram usable as a practice sheet.
