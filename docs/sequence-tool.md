# Sequence Tool

The Sequence Tool records an ordered path of buttons or keys.

It is useful for:

- melodies
- scale paths
- arpeggios
- exercises
- fingering movement
- left-hand bass movement

## What a sequence contains

A sequence stores the order in which buttons/keys should be played. This differs from Selection Tool, which marks an unordered group.

## Display modes

Sequences can display:

- numbers
- straight arrows
- curved arrows
- numbers plus arrows

Numbers are useful when the exact order matters. Arrows are useful when you want to show movement across the keyboard.

## Playback

If sound is enabled, the sequence can be played back in order.

Playback is meant as an audible check of the path rather than a full performance engine.

## Export

Sequence markings are part of the diagram and are included in SVG/PNG exports.

## Tips

For scale diagrams, compare the Sequence Tool with Scale Finder. Scale Finder generates a path automatically; Sequence Tool is better when you want a custom path.

## Rendered notation view

When a recorded sequence contains at least one button, the top toolbar can show a `Show notation` button. The sequence notation is a simple quarter-note sketch generated from the recorded button order. It is intended as a quick reading aid, while the diagram arrows and numbers remain the primary sequence display.

In Stradella mode, sequence notation uses the same bass/chord staff-placement rule as the Bass Pattern Player: bass and counterbass notes are placed at or below the bass-clef middle line D, while chord buttons are placed above it.

The notation panel includes **Download SVG** for saving the rendered staff notation. A collapsible **Notation help** section is available in the Sequence Tool controls.
