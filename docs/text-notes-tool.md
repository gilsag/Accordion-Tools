# Text Notes Tool

The Text Notes Tool places custom text directly on the diagram.

It is useful for:

- lesson comments
- reminders
- chord names
- exercise instructions
- practice annotations
- explaining a diagram to someone else

## Adding notes

Open **Text Notes** in the Tools panel and add a note. Notes can contain multiple lines.

They are displayed on the SVG diagram, not just in the side panel.

## Editing and clearing notes

Existing notes can be changed or removed from the tool panel.

## Export

Text notes are included in SVG/PNG downloads because they are drawn into the diagram.

## Tips

Text notes work well with:

- hidden button labels for clean diagrams
- custom diagram titles
- Scale Finder paths
- Chord Finder results
- Sequence arrows
