# Annotate Diagram Tool

The Annotate Diagram tool adds custom text directly to the SVG diagram. It replaces the older Text Notes workflow with a click-first, inline editing workflow.

## Basic workflow

1. Open **Annotate Diagram** in the Tools panel.
2. Choose the button position and text style for new annotations.
3. Adjust **Text size**, **Distance from center**, **Bold**, **Italic**, color, and font as needed.
4. Click a button or an empty diagram location.
5. Type the annotation directly on the diagram.
6. Press **Enter** to save, **Shift+Enter** for a new line, or **Esc** to cancel.

## Button-attached annotations

Button annotations are attached to a specific button and can be placed at center, top, bottom, left, right, or one of the four corners. The **Distance from center** slider controls how far non-center annotations are placed from the button center toward the chosen anchor. Center annotations ignore this slider.

## Local style settings

The current text size, color, font, bold, italic, and distance settings are stored with each annotation when it is created. Changing the controls later affects new annotations, not existing ones. The default distance from center is 50%.

## Free-position labels

Clicking empty space creates a free-position label. These are useful for titles, explanations, or notes that refer to a larger area rather than one button.

## Annotation list

The Annotate Diagram panel lists all current annotations. Each item shows a short preview and location label. Use the **×** button to delete a single annotation, or **Clear annotations** to remove all annotations.

## Export

Annotations are included in SVG and PNG downloads because they are drawn into the diagram.
